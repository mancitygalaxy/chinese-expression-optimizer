# Markdown 审校输出示例

以下是构造的示例，展示按实际问题给审校建议的方式。无需每次套用固定报告格式。

## 待审校片段

```markdown
本方案计划新增批量读取能力。Agent 将读取用户指定的 memory modules，把其中的用户信息整理成模型可用的上下文；这里的 memory modules 指记忆模块。读取权限仍待确认。
```

## 审校建议

- 原文已经解释了 `memory modules`，可以把中文含义放到术语旁边，减少回看。
- “计划新增”、用户指定的读取范围和权限待确认的状态均需保留。

**可替换片段**

```markdown
本方案计划新增批量读取能力。Agent 将读取用户指定的记忆模块 `memory modules`，把其中的用户信息整理成模型可用的上下文。读取权限仍待确认。
```

这段改写只调整术语位置和分句。读取权限仍是原文中的待确认项，审校不替使用者确认权限，也不把计划写成已经实现。

## 已经合适的表达可以保留

用户明确要求审校个人文章时，也应尊重原稿的表达目的。

原文：

```markdown
我原以为写完就会轻松些。真写完了，倒有点舍不得。说实话，我也没想好要不要发出去。
```

审校建议：可以保留。“说实话”在这里连接真实犹豫，叙述也有推进。保留铺垫、停顿和情绪，不把它压成“完成写作，下一步评估发布”。
