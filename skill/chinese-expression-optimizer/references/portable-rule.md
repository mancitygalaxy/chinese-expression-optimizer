# 可复制的中文表达优化规则

用户需要一段轻量规则时使用；不默认把这份内容重复加载到完整 Skill。

```markdown
面向中文读者，保留原意、信息和作者语气，让文字读起来更顺。默认在表达层面润色，允许调整用词、语序、句式和衔接，不要求逐字贴着原句；已经合适的句段可以保留。压缩、摘要、扩写或改变文体按用户要求处理。

- 保留独立信息、推理、例子、判断、情绪和有意义的修辞，可以合并重复表达。
- 保留事实、数字、名称、来源、归因及否定、条件、范围、时间和完成状态。“可能”不改成“确定”，“计划”不改成“已完成”。
- 具体内容只来自原文或用户材料；原文概括时允许继续概括。可疑事实另行提示，润色不代表已完成事实核验。
- 普通概念优先用中文，必要术语和准确标识保留原文。命令、路径、字段名、代码符号用反引号标出，按读者需要解释；代码、引文、链接目标和结构化数据保持准确。
- 正式工作文档让读者看清对象、动作、条件和结果；个人文章按表达目的保留叙述顺序与节奏。不统一改成汇报、聊天稿或行动清单。
- 套话、连接词、被动句、排比和长短句按语境判断，只改实际的冗长、空泛或不顺。必要的正式表达、真实对比和礼貌话可以保留。
- 去套话时可删没有依据的宣传夸饰，保留原有目标和实际主张；有依据的幅度、限定和作者真实立场照原文保留。
- 有认可样稿时参考其表达习惯，不带入样稿中的事实和经历；没有样稿时以原稿语气为准。

普通交流、新稿创作、原回答保存和常规排版只做必要检查。正式文档需要专项审校、批量统一文风，或用户明确要求润色、改写、去套话时，再执行专项审校；格式和落盘动作本身不触发完整流程。

改后对照原文检查新增、遗漏和判断强度变化，再通读改动段落，确认句间关系、信息和语气保持合适。交付形式按请求决定，不固定附加改写报告。

新增或修改 Markdown 后标明“中文表达自检：已做”，重要文档说明复查范围；未新增或修改 Markdown 时标明“中文表达自检：不适用”。部分完成时如实说明。
```
